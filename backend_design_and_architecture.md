# ⚙️ Backend Architecture & AI Implementation (Django)

## 🏗️ Core Architecture & Tech Stack
- **Framework**: Django + Django REST Framework (DRF)
- **Database**: PostgreSQL (Relational data) + PostGIS (For spatial/location clustering)
- **Caching & Message Broker**: Redis (For fast API responses & Celery queue)
- **Async Workers**: Celery (To run Gemini AI tasks in the background without freezing the app)
- **AI Engine**: Google Gemini API (For clustering, severity scoring, and summaries)
- **Cloud Storage**: AWS S3 or Cloudinary (For storing user-uploaded photos)

---

## 🧠 The "Winning" Feature: AI Complaint Clustering + Severity Engine

*Why this wins: Instead of an MP seeing 1,000 separate complaints, they see 10 AI-clustered "Core Issues".*

### How it works (The Pipeline):
1. **Data Ingestion**: A citizen submits a complaint (Text/Voice/Photo).
2. **Pre-processing (Voice/Photo)**: 
   - Voice is converted to Hindi/English text (via Google Speech-to-Text or Gemini 1.5 Pro audio capabilities).
   - Photo is passed to Gemini Vision: "Does this photo show a civic issue? If yes, what is it?" (Filters fake images).
3. **The Celery Queue**: Complaint is pushed to a background Celery task.
4. **AI Clustering (Gemini LLM / Embeddings)**:
   - The backend runs a spatial query (PostGIS): *Get all recent complaints in a 2km radius.*
   - Backend sends this batch to Gemini with the prompt: *"Here is a new complaint and a list of existing issues. Does this new complaint describe the exact same physical problem as any existing issue? If yes, return the Cluster ID. If no, create a new cluster."*
5. **Severity Scoring (Gemini)**:
   - Gemini calculates a score (1-10) based on keywords (e.g., "accident", "bleeding", "dangerous") and volume (number of people in the cluster).
6. **Database Update**: The cluster priority score is updated and immediately pushed to the MP's dashboard via WebSocket (or simple polling).

## 🗄️ Database Schema Overview

**1. User Model (Citizens & Admins)**
- `phone_number` (Primary Auth)
- `role` (Citizen / Admin / MP)
- `default_language`

**2. Complaint Model**
- `id`, `user_id`, `timestamp`
- `raw_text`, `audio_url`, `photo_url`
- `location` (PostGIS PointField - Lat/Long)
- `ward_name`, `village_name`
- `ai_category` (Auto-tagged)
- `cluster_id` (Foreign Key to IssueCluster)

**3. IssueCluster Model (The core of the MP Dashboard)**
- `id`, `cluster_title` (Generated by AI)
- `center_location` (Average GPS of all complaints)
- `severity_score` (1-10, updated by AI)
- `sentiment_score` (Positive/Negative/Frustrated)
- `status` (Pending / Forwarded / Resolved)
- `department` (Auto-assigned: PWD, Water Board, etc.)

## 🚀 Scalability & Performance Strategy (How to prove it handles scale)

1. **Async AI Processing**: The biggest bottleneck in Hackathons is waiting for API calls. **Never run Gemini API in the main Django request cycle.** Use Celery. The user gets a "200 OK - Processing" immediately, and they see the priority score a few seconds later.
2. **Geospatial Indexing**: Using `PostGIS` allows lightning-fast radius searches (`ST_DWithin`). This is crucial because clustering only makes sense for issues happening in the same geographical area.
3. **Database Indexing**: Indexes on `cluster_id`, `status`, and `ward_name` for instantly loading the MP Dashboard.
4. **Caching the Dashboard**: The MP dashboard stats (Total complaints, Top 5 issues) are cached in Redis and updated every 5 minutes, ensuring the dashboard loads in <100ms even with 100,000 complaints.

## ⭐ Advanced "Wow" Backend Features

1. **Auto-Escalation Engine**: A cron job runs every night. If a "High Severity" cluster is in "Pending" status for > 7 days, it automatically sends an SMS to the MP's personal assistant.
2. **Predictive Text / Similar Issue Prompt**: When a user types a complaint, the backend instantly searches PostGIS/Embeddings and returns: "30 people near you already reported a water issue. Do you want to just upvote theirs?"
3. **Weekly Gemini Report Generation**: A weekend Celery task compiles all data from the past 7 days, sends it to Gemini: *"Write a 2-paragraph summary for the MP about this week's civic performance."* and emails it as a PDF.
4. **Fake/Spam Detection**: Rate limiting by phone number + Gemini Vision checking if the uploaded photo is genuinely a street/civic issue or just a random selfie.
